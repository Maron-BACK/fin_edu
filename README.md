# 금융교육 전문강사 표준교재 문제집

금융감독원 **금융교육 전문강사 인증시험** 대비 4지선다 문제집입니다.
「금융교육 전문강사 표준교재」 개정판(2025.12)을 기반으로 만들었습니다.

- 챕터별 문제집 **16개 · 289문항** (풀면 바로 정오 판정 + 해설)
- 실전 모의고사 **2회 · 80문항** (실전처럼 채점 없이 풀고, 마지막에 정답표)

## 사용법

`index.html` 파일 하나로 전부 동작합니다. 브라우저로 열기만 하면 됩니다.

### GitHub Pages로 배포하기

1. 이 저장소를 GitHub에 업로드
2. **Settings → Pages → Source**를 `Deploy from a branch`로 두고 브랜치는 `main`, 폴더는 `/ (root)` 선택
3. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속

휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 기능

| | |
|---|---|
| **챕터 문제집** | 보기를 누르면 즉시 정오 판정 + 회색 해설. `오답 모아보기`로 틀린 문항만 순회 |
| **모의고사** | 즉시 채점 없이 답만 선택(변경 가능), 경과시간 표시. `채점하기` → 점수 + 정답표(문항·영역·정답·내 답·O/X) |
| **이동** | 하단 `이전`/`다음`, 좌우 스와이프, PC는 방향키 · 숫자 1~4로 답 선택 · `Esc`로 목차 |
| **기타** | 다크모드 자동 대응, iOS 노치·홈바 여백 처리, 외부 라이브러리·네트워크 요청 없음 |

풀이 기록은 **브라우저 메모리에만** 저장됩니다. 목차와 챕터를 오가는 동안에는 유지되지만, 페이지를 새로고침하면 초기화됩니다.

## 파일 구조

```
index.html      단일 실행 파일 (문항 데이터 포함, 약 120KB)
data/*.json     원본 문항 데이터 (챕터 16 + 모의고사 2)
shell.html      index.html 생성용 템플릿
build_index.py  data/*.json → index.html 빌드 스크립트
```

문항을 고치려면 `data/`의 JSON을 수정한 뒤 다시 빌드하세요.

```bash
python3 build_index.py
```

### 문항 데이터 형식

```json
{
  "t": "주제 라벨",
  "q": "문제 (HTML 가능, <u>옳지 않은</u> 등)",
  "box": "사례 제시문 (선택)",
  "o": ["선지1", "선지2", "선지3", "선지4"],
  "a": 3,
  "e": "해설 (모의고사는 비움)"
}
```

## 검수

- 자동 검사: 선지 수 · 정답 범위 · 선지 중복 · 문제 중복 · 해설↔정답 일치 · 태그 균형 — 이상 없음
